#  Natural Language Processing (NLP)

Repository ini merupakan bagian dari tugas dalam program **“ASAH led by Dicoding”**, di mana saya menerapkan berbagai konsep yang telah dipelajari dari modul-modul pembelajaran terkait **Natural Language Processing (NLP)** dan **Machine Learning**.  

Proyek ini mencakup proses lengkap mulai dari pengumpulan data hingga evaluasi model dengan hasil akurasi yang tinggi.

---

##  Kriteria Utama
- Data diperoleh melalui proses **scraping mandiri**
- Melakukan **ekstraksi fitur** dan **pelabelan data**
- Menggunakan **algoritma machine learning** untuk pelatihan
- Akurasi pada **testing set ≥ 85%**

---

##  Kriteria Tambahan
- Menggunakan **algoritma deep learning**
- Akurasi pada **training dan testing set ≥ 92%**
- Dataset memiliki **minimal tiga kelas**
- Jumlah data **≥ 10.000 sampel**
- Melakukan **tiga percobaan skema pelatihan berbeda**
- Melakukan **inference/testing** menggunakan file `.ipynb` atau `.py` dengan output kategorikal  
  *(contoh: negatif, netral, positif)*

---

 *Repository ini menunjukkan penerapan nyata konsep NLP untuk membangun model analisis teks yang akurat dan efisien.*
